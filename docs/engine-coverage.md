## Simulation harness

```
npm run simulate -- -m 2 -m 4 -m 6 -n 200 -s 1
```

Plays 200 random-legal-intent matches per mode from seed 1, checking every invariant after every step. Result: exit code 0, all invariants held (see `scripts/simulate.ts --help` for options).
